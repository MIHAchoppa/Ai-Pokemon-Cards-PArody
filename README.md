# Ai-Pokemon-Cards-PArody
pokemon card parodys

## Pokemon Parody Chat API Integration

This project includes integration with the Poe API to interact with the Pokemon.parody model, which generates Pokemon card parodies using AI.

### Setup

1. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Configure your API key:**
   - Get your API key from [https://poe.com/api_key](https://poe.com/api_key)
   - Copy `.env.example` to `.env` and add your API key:
     ```bash
     cp .env.example .env
     # Edit .env and replace 'your_poe_api_key_here' with your actual key
     ```
   - Or export it directly:
     ```bash
     export POE_API_KEY=your_api_key_here
     ```

### Usage

#### Using Python Script

Run the script with a custom message:
```bash
python pokemon_chat.py "Hello world"
```

Or use the default message:
```bash
python pokemon_chat.py
```

#### Using curl

You can also interact directly with the Poe API using curl:

```bash
curl "https://api.poe.com/v1/chat/completions" \
    -H "Content-Type: application/json" \
    -H "Authorization: Bearer $POE_API_KEY" \
    -d '{
        "model": "Pokemon.parody",
        "messages": [{"role": "user", "content": "Hello world"}]
    }'
```

### API Details

- **Endpoint:** `https://api.poe.com/v1/chat/completions`
- **Model:** `Pokemon.parody`
- **Authentication:** Bearer token (POE_API_KEY)

See the [full documentation](https://creator.poe.com/docs/quick-start) for comprehensive guidance on getting started with the Poe API.

### Example Response

The API returns a JSON response with the Pokemon parody content generated by the model.
